# 三列中央列表卡片操作按钮位置调整

## 目标

在中央列表切换为三列网格时，用户仍能像单列模式一样在每张卡片右上角找到全部卡片操作按钮，降低卡片间寻找和操作入口的成本。

## 背景与已确认事实

- 公共中央列表卡片由 `src/components/central-list-layout.tsx` 提供；三列模式的卡片主体和底部操作栏分离布局。
- MCP 页面 `src/features/mcp/mcp-page.tsx` 当前仅在单列卡片标题行渲染编辑/启停/删除操作，三列模式将三者全部放入卡片底部操作栏。
- 提示词页面 `src/features/prompts/prompts-page.tsx` 当前仅在单列卡片标题行渲染编辑/删除操作，三列模式将二者全部放入卡片底部操作栏。
- Skills 页面 `src/features/skills/skills-page.tsx` 当前仅在单列卡片标题行渲染内容预览/移出中央库操作，三列模式将二者全部放入卡片底部操作栏。
- 三个页面的全局平台分配/启用按钮属于独立操作组，当前位于卡片底部；本次保持其位置和行为不变。

## 需求

1. MCP 中央列表在三列模式下，将每张卡片的编辑、启用/停用、删除按钮全部放在卡片主体标题区域右上角，与单列模式保持一致。
2. 提示词中央列表在三列模式下，将每张卡片的编辑、删除按钮全部放在卡片主体标题区域右上角，与单列模式保持一致。
3. Skills 中央列表在三列模式下，将每张卡片的内容预览、移出中央库按钮全部放在卡片主体标题区域右上角，与单列模式保持一致。
4. 三列模式下三个页面的全局平台分配/启用按钮仍保留在卡片底部操作栏，不改变其行为、可访问名称、图标和按钮样式。
5. 单列模式现有布局与行为保持不变；编辑、内容预览、移出中央库等按钮仍执行原有操作并维持焦点恢复逻辑。

## 验收标准

- [ ] 切换 MCP 中央列表至三列后，每张卡片标题区域右上角可见且可点击编辑、启用/停用、删除按钮；卡片底部不再重复渲染这些按钮。
- [ ] 切换提示词中央列表至三列后，每张卡片标题区域右上角可见且可点击编辑、删除按钮；卡片底部不再重复渲染这些按钮。
- [ ] 切换 Skills 中央列表至三列后，每张卡片标题区域右上角可见且可点击内容预览、移出中央库按钮；卡片底部不再重复渲染这些按钮。
- [ ] 三列模式下三个页面的全局平台分配/启用按钮仍位于底部操作栏且可正常使用。
- [ ] 现有单列模式、编辑弹窗打开/取消/关闭、内容预览/移出中央库及布局持久化相关测试继续通过，并补充或调整测试以验证上述 DOM 位置。

## 非目标

- 不为 Skills 增加编辑功能。
- 不改变公共三列网格列数、卡片尺寸、平台分配逻辑、编辑表单字段或后端接口。

## 技术备注

- 预计仅需调整 MCP、提示词和 Skills 页面中卡片操作组在三列模式下的渲染位置，并同步更新对应页面测试；公共布局组件无需改变。
- 当前无阻塞性待决策项。
