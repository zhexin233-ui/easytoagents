# ZCode

Using GLM Coding Plan in ZCode

[ZCode](https://zcode.z.ai/en) is a full-featured Agentic Development Environment (ADE) designed for long‑horizon tasks. With its proprietary ZCode Agent, multi‑framework compatibility, bot integration, and mobile remote control, ZCode enables AI agents to reliably complete development tasks that span lengthy and multi‑step workflows. When paired with GLM Coding Plan，[ZCode](https://zcode.z.ai/en) helps you more efficiently understand projects, write code, resolve issues, and accomplish complex development tasks.

## Step 1: Installing ZCode

Visit the [ZCode download page](https://zcode.z.ai/en)，provided by the team and install the version suitable for your operating system.

## [​](#step-2-configuring-glm-coding-plan) Step 2: Configuring GLM Coding Plan

1. Click the **Settings** button in the lower‑left corner，then navigate to the **Model Providers** page via the left sidebar.
2. In the **Z.ai Open Platform** section, enter your API Key. You may also click **Get API Key** or **Use Subscription**，to be redirected to the login page, after which the key will be automatically populated.

For manual configuration: if you intend to use your subscribed GLM Coding Plan, please ensure that the **OpenAI Base URL** and **Anthropic Base URL** are set to:<https://api.z.ai/api/coding/paas/v4><https://api.z.ai/api/anthropic>

## [​](#step-3-saving-and-switching-models) Step 3: Saving and Switching Models

After configuration, save your settings. You can then select the newly configured GLM model from the model‑switching menu in ZCode.
