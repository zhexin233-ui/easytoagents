# Custom Prompts

Deprecated. Use skills for reusable prompts

Custom prompts are deprecated. Use [skills](/codex/build-skills) for reusable instructions that Codex can invoke explicitly or implicitly.

Custom prompts (deprecated) let you turn Markdown files into reusable prompts that you can invoke as slash commands in both the Codex CLI and the Codex IDE extension.

Custom prompts require explicit invocation and live in your local Codex home directory (for example, `~/.codex`), so they're not shared through your repository. If you want to share a prompt (or want Codex to implicitly invoke it), [use skills](/codex/build-skills).

1. Create the prompts directory:

   ```
   mkdir -p ~/.codex/prompts mkdir -p ~/.codex/prompts
   ```
2. Create `~/.codex/prompts/draftpr.md` with reusable guidance:

   ```
   --- description: Prep a branch, commit, and open a draft PR argument-hint: [FILES=] [PR_TITLE=""</span><span style="color:#24292E;--shiki-dark:#E1E4E8">]</span></span> <span><span style="color:#24292E;--shiki-dark:#E1E4E8">---</span></span> <span></span> <span><span style="color:#24292E;--shiki-dark:#E1E4E8">Create a branch named </span><span style="color:#005CC5;--shiki-dark:#79B8FF">`dev/<feature_name>`</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> for this work.</span></span> <span><span style="color:#24292E;--shiki-dark:#E1E4E8">If files are specified, stage them first: $FILES.</span></span> <span><span style="color:#24292E;--shiki-dark:#E1E4E8">Commit the staged changes with a clear message.</span></span> <span><span style="color:#24292E;--shiki-dark:#E1E4E8">Open a draft PR on the same branch. Use $PR_TITLE when supplied; otherwise write a concise summary yourself.</span></span></code></pre> </li> 
   <li>
   <p>Restart Codex so it loads the new prompt (restart your CLI session, and reload the IDE extension if you are using it).</p> </li> </ol> 
   <p>Expected: Typing <code>/prompts:draftpr</code> in the slash command menu shows your custom command with the description from the front matter and hints that files and a PR title are optional.</p> 
   <h2><span>Add metadata and arguments</span><button title="Copy link to __codexlocalizedvalueprops__codextranslations u0010 add metadata and arguments"></button></h2> 
   <p>Codex reads prompt metadata and resolves placeholders the next time the session starts.</p> 
   <ul>
   <li><strong>Description:</strong> Shown under the command name in the popup. Set it in YAML front matter as <code>description:</code>.</li> 
   <li><strong>Argument hint:</strong> Document expected parameters with <code>argument-hint: KEY=<value></code>.</li> 
   <li><strong>Positional placeholders:</strong> <code>$1</code> through <code>$9</code> expand from space-separated arguments you provide after the command. <code>$ARGUMENTS</code> includes them all.</li> 
   <li><strong>Named placeholders:</strong> Use uppercase names like <code>$FILE</code> or <code>$TICKET_ID</code> and supply values as <code>KEY=value</code>. Quote values with spaces (for example, <code>FOCUS="loading state"</code>).</li> 
   <li><strong>Literal dollar signs:</strong> Write <code>$$</code> to emit a single <code>$</code> in the expanded prompt.</li> </ul> 
   <p>After editing prompt files, restart Codex or open a new chat so the updates load. Codex ignores non-Markdown files in the prompts directory.</p> 
   <h2><span>Invoke and manage custom commands</span><button title="Copy link to __codexlocalizedvalueprops__codextranslations u0018 invoke and manage custom commands"></button></h2> 
   <ol>
   <li>
   <p>In Codex (CLI or IDE extension), type <code>/</code> to open the slash command menu.</p> </li> 
   <li>
   <p>Enter <code>prompts:</code> or the prompt name, for example <code>/prompts:draftpr</code>.</p> </li> 
   <li>
   <p>Supply required arguments:</p> 
   <pre style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8;overflow-x:auto"><code><span><span>/prompts:draftpr FILES="src/pages/index.astro src/lib/api.ts" PR_TITLE="Add hero animation"</span></span></code></pre> </li> 
   <li>
   <p>Press Enter to send the expanded instructions (skip either argument when you don't need it).</p> </li> </ol> 
   <p>Expected: Codex expands the content of <code>draftpr.md</code>, replacing placeholders with the arguments you supplied, then sends the result as a message.</p> 
   <p>Manage prompts by editing or deleting files under <code>~/.codex/prompts/</code>. Codex scans only the top-level Markdown files in that folder, so place each custom prompt directly under <code>~/.codex/prompts/</code> rather than in subdirectories.</p> </article> </div> </div> </div>
   ```
