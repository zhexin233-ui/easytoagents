# 新增与编辑表单改为弹窗

## Goal

将 MCP、渠道档案、全局提示词的新增与编辑表单改为按钮触发弹窗，保留业务逻辑并验证表单生命周期。

## Requirements

- R1：MCP、Claude/Codex 渠道档案与全局提示词表单默认隐藏；列表区新增按钮打开空白表单，行内编辑按钮打开对应记录的表单。
- R2：移除 MCP 页面原有表单列，中央列表占用可用宽度；空状态说明指向真实的新增或导入按钮。
- R3：弹窗提供标题、说明、关闭及取消入口；支持 Escape、Tab 焦点循环和关闭后的焦点恢复；长表单可滚动，窄屏不溢出。
- R4：关闭时清理草稿与旧错误；保存成功关闭并刷新列表，失败在弹窗内提示且保留输入；保存期间防止重复提交和关闭，避免旧响应清理新草稿。
- R5：不改变创建/编辑 payload、行版本、敏感字段 keep 语义、OAuth 编辑限制、查询失效及无隐式 Apply 约束。

## Acceptance Criteria

- [x] AC1（R1、R2）：三类表单在首次打开页面时不可见，新增与编辑按钮均打开命名正确的弹窗；MCP 不再保留表单列。
- [x] AC2（R3、R4）：关闭、取消、Escape、Tab 循环和恢复焦点正常；重新新增不残留旧草稿、编辑状态或错误。
- [x] AC3（R4、R5）：保存成功关闭并刷新列表，失败保留输入；pending 阶段阻止重复提交和关闭；原有精确 payload 与敏感数据回归通过。
- [x] AC4（R3、R5）：类型检查、lint、格式检查、全量前端测试及构建通过；在隔离环境检查布局，不对真实配置执行写入。
