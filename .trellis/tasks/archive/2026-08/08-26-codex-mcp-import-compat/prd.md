# 修复 Codex MCP 导入兼容性与误判

## 目标

让可无损表达的 Codex 全局 MCP 正常导入中央库，并在无法导入时给出具体原因，消除截图中的兼容性误判与普通路径被误当作密钥的问题。

## 背景与证据

- 用户已批准创建任务，并在最终规划摘要后回复“可以”，批准按本方案实施。
- 只读核验本机配置的字段结构：共 6 项，4 个启用项显式携带 `type=stdio/http`，1 个启用项为 `node_repl`，`computer-use` 显式停用。未输出凭据、完整命令或环境变量值。
- 当前成功路径的合成 fixture 会移除 `type`（`src-tauri/src/mcp/service.rs:2077-2084`），未覆盖实际遇到的显式类型。
- 详细调用链、安全结构证据与基线测试见 `research/root-causes.md`；本任务不把导入失败等同于 MCP 服务运行失败。

## 需求

### R1 · 修复显式协议兼容性（P1）

当前 `parse_native_item` 仅允许 Claude 的显式协议，Codex 只要有 `type` 就走不支持分支（`src-tauri/src/mcp/import.rs:437-453`）。两个工具均应接受和结构一致的 `stdio`、`http`、`streamable_http`；省略类型时继续按 `command/url` 推断。类型与字段冲突、未知协议和 SSE 仍拒绝，不能静默猜测或丢失有语义的配置。

### R2 · 修复普通运行配置的敏感值误判（P1）

当前所有 env 值登记为秘密，再以文本脱敏前后是否变化判断普通字段合法性（`src-tauri/src/mcp/import.rs:61-105,500-510`；`src-tauri/src/security/mod.rs:55-95`）。本机 `node_repl.command` 包含 `env.NODE_REPL_NODE_PATH` 的普通绝对路径，因此被拒绝。

- 展示隐藏与凭据识别应区分：明确识别的运行路径、开关或超时值不应仅因和普通字段重叠而阻止导入。
- env/header 仍不直接展示值；私有配置和后续同步必须保留原值。
- 敏感字段、显式登记的凭据、可识别令牌及用途不明的 env 值继续保守保护；不通过长度或熵阈值、忽略所有 env 值放行。
- 相同内容同时出现在普通运行变量与凭据字段时，凭据保护优先。已知真实密钥出现在其它候选普通字段时仍拒绝。
- 首次扫描、确认后重扫、同进程先创建/编辑或生成预览后再扫描，以及重新构造进程状态后的判断保持一致。

### R3 · 给出具体且安全的诊断（P2）

当前多个错误汇总为通用提示（`src-tauri/src/mcp/import.rs:413-417,448-451,483,495-496`）。原因应指出稳定字段名和规则，例如协议不支持、`type` 与 `command/url` 冲突、`args` 类型错误、`env_http_headers` 不可保真，或普通字段命中凭据。不得拼接原始值、配置片段或未经筛选的解析错误。沿用既有 `reason` DTO 和逐项展示（`src/features/mcp/mcp-import-dialog.tsx:125-150`）。

### R4 · 保持现有安全与所有权边界

- 停用项保持只读、不可选，不擅自启用或接管。
- 保留显式勾选、同名私有配置比较、来源校验、事务、旧基线漂移与重复确认保护。
- 扫描、确认导入和生成预览均不改原生文件；规范化在后续独立同步预览中展示，经用户 Apply 才写入。
- 无效项不妨碍其它合法条目；RPC、错误、证据和日志不泄漏真实密钥。

## 验收标准

- [x] **AC1（R1）**：隔离 TOML fixture 中显式 stdio/http/streamable_http 与省略 type 的等价配置可选择并导入；同名等价复用不受冗余 type 影响。
- [x] **AC2（R2）**：合成 node_repl 命令包含普通运行路径时可导入；路径、开关、超时与普通字段的同条目或跨条目重叠不产生错误的凭据命中。
- [x] **AC3（R2、R4）**：API key、短凭据、未知用途环境值及跨条目重复凭据仍被拦截或脱敏；运行值分类不能覆盖同值的凭据分类。env/header 值始终隐藏。
- [x] **AC4（R2）**：create/update、confirm、preview 和重扫的登记策略一致；新建 redactor 重扫仍作出相同判断。普通字符串的 JSON 规范化不构成敏感值证据。
- [x] **AC5（R3）**：错误原因指出具体字段/约束，不回显敏感值；前端展示原因且只允许选择可导入项。
- [x] **AC6（R1、R4）**：导入前后原生字节一致；隔离 fixture 后续 Preview/Apply 仅规范化已选项，保留可表达 extra、敏感配置、停用项、未选项与无关内容。
- [x] **AC7（R4）**：既有导入、冲突、过期、事务和脱敏测试不回退；补充真实结构对应的合成回归并通过生成绑定检查与 `pnpm check`。

## 范围外

- 启动、安装、升级或排查 MCP 服务进程本身。
- 自动导入、自动启用停用项、自动 Apply 或改写用户真实 Codex/Claude 配置。
- 新增 SSE、`env_http_headers` 或原生停用状态的中央模型支持。
- 放宽中央配置验证、改造数据库 schema/同步引擎、变更 Provider 凭据策略。
- 保证所有用途不明的环境变量都自动认定为非秘密；此类仍保守处理。
