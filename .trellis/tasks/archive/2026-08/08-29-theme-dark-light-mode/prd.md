# 前端新增暗色与亮色主题模式

## Goal

EasyToAgents 桌面前端支持亮色（白天）与暗色（黑夜）两种外观模式。用户可在壳层顶栏切换；默认跟随系统外观，手动选择在应用重启后保持。

## Requirements

- 三态切换：亮色 / 暗色 / 跟随系统；默认「跟随系统」。
- 切换入口位于应用外壳顶栏（TopBar），使用可访问的按钮组：每个选项有稳定的可访问名称与 `aria-pressed` 状态，当前选中项有可见与辅助技术可感知的标识。
- 用户选择持久化到 localStorage，应用重启后恢复；存储缺失或值非法时回退到「跟随系统」。
- 「跟随系统」模式下，系统外观变化实时反映到应用，无需重启或重新聚焦。
- 暗色模式下所有界面保持可读与对比度：侧边栏、顶栏、卡片/面板、表单输入框、对话框与遮罩、导入向导、状态徽章（成功/警告/阻断/失败）、警告与错误提示区、代码块（pre）区域适配暗色；原生控件与滚动条外观（`color-scheme`）随模式切换。
- 亮色模式的视觉外观与现状一致，是回归约束（新增的切换控件除外）。
- 无闪烁（no-flash）：应用启动首帧即按「持久化偏好 / 系统外观」渲染目标模式，不出现先亮后暗或先暗后亮的闪变。

## Constraints

- 仅前端层：`src/` 与 `index.html`；不涉及 Rust 后端、生成绑定或 RPC。
- 遵循项目既有规范：localStorage 仅做窄用途持久化（try/catch 包裹、版本化 key）；可复用行为收敛为共享 hook；主题色走 CSS 变量 + Tailwind v4 `@theme inline` 体系。
- 现有测试断言的浅色工具类（如 `bg-amber-50`、`bg-red-50`）必须保持有效；暗色适配以追加 `dark:` 变体实现，不重命名既有浅色类。
- 不引入新的全局状态库或 Context；主题不属于 server state，不进 TanStack Query。

## Acceptance Criteria

- [ ] 顶栏提供亮/暗/跟随系统三态切换，选中态有 `aria-pressed` 与 title，点击立即生效。
- [ ] 偏好持久化（key 遵循 `easytoagents.<domain>.<name>.v1` 约定），重启后保持；非法值回退「跟随系统」。
- [ ] 「跟随系统」模式下变更系统外观，应用实时跟随。
- [ ] 暗色模式下逐页检查总览、项目列表/详情、MCP、Skills、Claude/Codex 工具页、首次运行向导及全部对话框：无白底残留、无可读性缺陷。
- [ ] 亮色模式外观与改动前一致。
- [ ] 首帧无主题闪变。
- [ ] `pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm test --run` 全部通过；新增测试覆盖：偏好持久化与非法值回退、系统外观监听、`dark` class 应用、切换控件 aria 状态。
